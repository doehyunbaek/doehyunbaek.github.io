Methodology

The reference’s footnote specifies removing price-linked terms. Using Numbeo’s published formula, the resulting score is:

100 + safety / 2 + healthcare / 2.5 − commute / 2 − pollution × 2 / 3 + climate / 3

Purchasing power / 2.5, housing price-to-income ratio, and −cost of living / 10 are excluded. The constant 100 does not affect ranks. We rank this derived score for Y and the unadjusted Cost of Living Index for X. All positions are computed from scraped data—none are transcribed from the image. The default displays cities selected in the reference; “All cities” reveals the complete dataset, and search can find any city.

Each index is ranked within the full dataset: percentile = (average rank − 1) / (city count − 1) × 100. Tied index values share an average rank. Region filters and search never change these percentiles. The four quadrants split at the median (50th percentile), not at an absolute standard of affordability or well-being.
