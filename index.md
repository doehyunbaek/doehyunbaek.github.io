# Research

My mission as a researcher is to develop simple yet effective techniques to make public software better.
Specifically, I am interested in these research topics:
- LLMs for software engineering
- Dynamic analysis

# Papers

[ASE 2025]<br>
**Execution-Aware Program Reduction for WebAssembly via Record and Replay**<br>
<u>Doehyun Baek</u>, Daniel Lehmann, Ben Titzer, Sukyoung Ryu, Michael Pradel.<br>
TLDR: Record and replay can speed up program reduction by targeting and isolating the bug-triggering function.<br>
[[paper]](https://arxiv.org/abs/2506.07834)[[artifact]](https://github.com/sola-st/rr-reduce)[[talk]](https://youtu.be/vaNEGiQPs54)

**Wasm-R3: Record-Reduce-Replay for Realistic and Standalone WebAssembly Benchmarks**<br>
